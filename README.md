# Dieguinho Entregas
- `index.html` estrutura | `css/styles.css` visual | `ts/main.ts` lógica | `js/main.js` gerado | `data/config.json` marca, contatos e tarifas
- Editar `ts/main.ts` e rodar `npx tsc` para gerar `js/main.js`.
- Abrir com servidor local (ex.: extensão Live Server) ou GitHub Pages; o `config.json` não carrega com duplo clique (file://).
